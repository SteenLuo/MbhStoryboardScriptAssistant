# 望川封面工作台（WangChuan Cover Studio）设计

## 目标与边界

在仓库根目录新增独立的 `cover-studio/` React + TypeScript 本地应用，用于制作抖音视频封面。它不改变现有 `app/` 服务，不使用后端、登录、云端同步、素材后台或 AI 图片生成接口。用户导入的图片只在本地浏览器中处理。

工具提供底图、人物贴图、文字三个基础图层，支持 3:4 竖版（1080×1440）和 4:3 横版（1440×1080）两种封面。两种比例共享图片与文字内容，但分别保存布局。

## 交互与视觉结构

采用固定三栏专业编辑器：

- 顶栏：比例切换、导入/替换底图、导入/替换人物贴图、重置模板、导出当前比例、同时导出两种比例。
- 左栏：图片素材入口以及底图、人物、文字图层列表。人物与每一条文字可独立隐藏。
- 中栏：按窗口自适应缩放的实时预览画布。其 CSS 显示尺寸可变，但内部 SVG 坐标恒为该比例的导出尺寸。
- 右栏：当前选中图层的属性。背景显示裁切位置、亮度和暗化；人物显示缩放与恢复默认；文字显示内容、字号、颜色、字重、描边和阴影。

默认模板是高对比口播/AI 工具内容样式：深蓝黑渐层背景、暗化遮罩、暖色强调、粗体白字、深色描边和阴影。人物初始放在竖版右下、横版右侧或右下。默认三条文字依次为主标题、补充说明、辅助信息。

## 状态模型与持久化

应用状态分为共享内容与比例专属布局：

- `assets`：背景图和人物图的本地引用；`textLines`：文字内容、字体风格、删除状态与固定 ID。
- `layouts['3x4']` 和 `layouts['4x3']`：背景裁切 X/Y、亮度、暗化、人物 X/Y/scale/visible、每条文字的 X/Y/fontSize/visible。
- 默认模板函数为两种比例生成各自合理的初始布局。首次进入某比例时使用该默认值；切换比例时只读取目标比例布局。

配置存入 `localStorage`。导入图片先经浏览器 File API 校验为常见图像格式，并以浏览器本地 IndexedDB 保存数据 URL；刷新后先恢复配置，再恢复素材。若空间不足，保留可保存的配置并展示明确的中文提示，不进行上传或回退到外部服务。

## 画布、拖拽与导出

中间画布使用 React 管理的 SVG：背景 `<image>` 通过 `preserveAspectRatio="xMidYMid slice"` 铺满且不变形，裁切位移由 SVG transform 控制；人物为独立 `<image>`；每条文字为独立 SVG `<text>`。文字是由浏览器渲染的可编辑导出文字对象，不通过图片生成模型制作标题或排版。

鼠标/指针拖拽通过 SVG viewBox 和实际 DOM 尺寸换算为导出坐标，故预览缩放不影响保存位置和导出尺寸。人物缩放支持属性滑块、加减按钮和鼠标滚轮。选中边框与手柄只在编辑预览层渲染，永不进入导出 SVG。

导出时克隆并序列化仅含视觉内容的 SVG，再按目标尺寸加载到离屏 canvas 并输出 PNG：

- `wangchuan-cover-3x4.png`：1080×1440。
- `wangchuan-cover-4x3.png`：1440×1080。

双比例导出按各自已保存布局顺序生成。该链路复用同一视觉 SVG，从而保证 PNG 与预览内容一致。

## 错误处理

为以下情况提供中文且可操作的提示：不支持/损坏的图像文件、浏览器无法读取文件、IndexedDB 或 localStorage 空间不足、SVG/Canvas 转换失败、浏览器阻止下载。空状态显示“导入背景图”“导入人物贴图”提示，未导入素材时仍显示默认高对比模板背景和文字。

## 验证

实施后应完成：

1. 运行生产构建并修复构建错误。
2. 验证默认布局、两种比例状态隔离、文本行增删和重置逻辑。
3. 在本地浏览器手工检查背景/人物导入、比例切换、拖拽、缩放、图层隐藏、刷新恢复和错误提示。
4. 导出两种 PNG，检查尺寸、文件名、无编辑器控制元素，并与各自预览比对。

## 非目标

不实现账号体系、网络上传、云端同步、素材管理后台、协作、复杂仪表盘或任何 AI 生成图像/自动排版功能。
